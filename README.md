# ⛪ Iglesia Vida Nueva - Landing Page

![Version](https://img.shields.io/badge/version-2.0.0-blue)
![Tailwind](https://img.shields.io/badge/Tailwind-3.4-38bdf8)
![License](https://img.shields.io/badge/license-MIT-green)

Landing page moderna y profesional para la Iglesia Vida Nueva, diseñada con Tailwind CSS. Incluye modo oscuro, animaciones, galería interactiva, sistema de eventos, blog devocional y mucho más.

## 🌟 Características

### ✨ Diseño y UX
- 🎨 Diseño elegante con paleta dorada y azul profundo
- 🌙 Modo oscuro con persistencia en localStorage
- 📱 Totalmente responsive (mobile-first)
- 🎭 Animaciones suaves y transiciones
- 🔄 Loader inicial animado
- 📍 Scroll spy en navegación

### 🛠️ Funcionalidades
- 📅 Sistema de eventos con calendario interactivo
- 🎵 Reproductor de sermones en audio
- 📸 Galería con lightbox
- 💬 Carrusel de testimonios automático
- 📝 Formulario de contacto con validación
- 💝 Sistema de donaciones interactivo
- 📖 Devocional diario
- 📰 Sección de blog/artículos
- 🔔 Notificaciones toast
- 📊 Contador de miembros en tiempo real

### 🚀 Performance
- ⚡ Carga optimizada
- 🖼️ Lazy loading de imágenes
- 📦 CSS y JS inline (sin dependencias externas excepto CDN)
- 🎯 SEO optimizado
